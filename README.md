# .github

Shared defaults for the `griton-ai` organization.

| Path | Purpose |
|---|---|
| `profile/README.md` | Organization profile shown on the GitHub org page |
| `.github/ISSUE_TEMPLATE/` | Default issue templates (Task, Bug) for repositories without their own |
| `pull_request_template.md` | Default pull request template |

Repositories in the organization use squash merge only and delete merged branches automatically.
